# Detection Coverage

Generated: `2026-09-26T19:28:33Z`

This page is a **curated selection**, not the size of the corpus.
It picks the highest-scoring rules per threat family from the set
the engine loads, so its numbers are smaller than the executable
total by design. For the corpus figures — executable, on disk, and
why they differ — see
[the detection truth table](https://github.com/beenuar/AiSOC/blob/main/docs/detections/truth-table.md).

Candidates are the rules whose ids appear in the compiled ruleset,
which is the same authority the truth table uses. It used to be the
directory layout, and that stopped being the same thing once the
Sigma compiler began translating rules where they sat: rules under
`_quarantine/` that the engine loads were skipped for their path.

## How to audit

The curated rule IDs are listed in [`marketplace/curated.json`](https://github.com/beenuar/AiSOC/blob/main/marketplace/curated.json) under each family. Every entry has a `path` field pointing at the on-disk YAML. Run `pnpm marketplace:curate --check` in CI to enforce drift; run `python3 scripts/curate_detections.py` locally to regenerate.
