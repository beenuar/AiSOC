# aisoc-benchmark

Grade **any** SOC agent on a common corpus — including one that is not ours.

A benchmark a vendor cannot run against their own product is a self-report.
This package is the boundary that makes it a standard instead: implement one
method, get graded on the same incidents by the same code.

```bash
pip install -e packages/aisoc-benchmark          # published to PyPI in v8.1

aisoc-benchmark corpus                            # what is in the corpus
aisoc-benchmark run --agent-url https://your-agent/investigate \
                    --agent-name your-product --agent-version 2.1
```

## Implementing an agent

One method. How your agent reaches evidence — model, tools, prompts,
architecture — is deliberately out of scope: prescribing them would grade
architecture rather than outcomes, and would exclude every agent that does
not look like ours.

```python
from aisoc_benchmark import AgentVerdict, BenchmarkIncident

class MyAgent:
    name = "my-product"
    version = "2.1"

    async def investigate(self, incident: BenchmarkIncident) -> AgentVerdict:
        result = await my_platform.triage(incident.as_dict())
        return AgentVerdict(
            disposition=result.verdict,            # malicious|suspicious|benign|unknown
            confidence=result.confidence,
            techniques=result.attack_techniques,
            cited_indicators=result.indicators,    # graded against the evidence
            proposed_actions=result.actions,
            narrative=result.summary,
        )
```

Or expose an HTTP endpoint that takes the incident as JSON and returns the
same shape, and point `--agent-url` at it.

## What is measured, and why

Accuracy is the least interesting number here. Three others are the reason
this exists:

**Hallucination rate** — the fraction of concrete indicators an agent cites
that appear nowhere in the evidence it was given. Measured, not estimated.
An agent that invents a plausible IP address to justify a verdict is doing
the most dangerous thing an analyst-replacement can do, and no accuracy
figure reveals it. Graded on abstentions too: declining to conclude while
citing an invented address is still inventing it.

**Abstention rate** — published beside accuracy, and accuracy is computed
over answered incidents only. Otherwise an agent raises its score by
abstaining more, and "I do not know" is a correct answer that a
forced-choice benchmark punishes — which trains agents to guess.

**Calibration gap** — mean confidence when right minus mean confidence when
wrong. Near zero means the confidence score carries no information, and
everything downstream that gates on a threshold is gating on noise.

Plus containment accuracy (any overlap with the expected actions counts —
requiring an exact set would grade an agent on matching our vocabulary
rather than on containing the incident), latency, tokens and cost per
incident.

Depth — tool calls, distinct tools — is reported but **not scored**. An
agent that reached the right answer in one step is not worse than one that
took twelve. Depth explains a score; it is not a score.

## Provenance

Every incident declares where it came from, and the runner refuses a corpus
that does not. The shipped corpus is `synthetic: 200` and says so, first
line of every report, before any figure.

A number computed over synthetic incidents is a synthetic number. A
scoreboard that omits that is misleading even when every figure in it is
arithmetically correct, and a reader who sees `0.94` before they see
`synthetic` has already formed an impression the caveat will not undo.

Valid values: `synthetic`, `public-dataset`, `real-anonymised`,
`adversary-emulation`.

## Corpus

`corpus/soc-agent-benchmark-v1.json`, generated by `build_corpus.py` from the
in-tree eval data rather than hand-maintained — two hand-edited copies of 200
incidents drift within a release, and the published figure then describes a
corpus nobody has.

## Failure handling

An agent that raises, times out or returns nonsense is scored as an
**abstention with the failure named**, never as a wrong answer and never as
an exception that ends the run. A harness that dies on one bad response
grades nothing, and the entrant reasonably assumes the fault is ours.

Latency is measured by the harness rather than trusted from the agent: it is
the one number an entrant has an incentive to shade.
